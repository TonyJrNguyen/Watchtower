# Lateness is recorded by hand until the time clock exists; the rules don't care about the source

The automated time clock (rotating code plus a presence signal) is deferred to Phase 3 because the presence mechanism (G51) hasn't been chosen. Until then the Administrator records an **arrival time** only for late arrivals, and no entry means on time. Grace, late penalty, deduction and anomaly rules apply to a manual arrival time exactly as they will to a clocked one.

## Consequences

- When the time clock arrives, only the source of the arrival time changes. No rule changes, and manual entry narrows to correcting clock records.
- The arrival time records which source produced it.
- Accepted cost: a late arrival nobody notices has no effect, so the bonus rests on the Administrator's attention until Phase 3.
